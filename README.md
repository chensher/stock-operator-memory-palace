# 作手的房子 · 3D 记忆宫殿

用空间、物件和文字阅读《股票作手回忆录》。一座可自由探索的旧华尔街宅邸，八间房、24件互动物品，对应原书全部章节，包含约17,500字中文原创转述与叙事。

[在线体验](https://stock-operator-memory-palace.wzcbkjg8kt.chatgpt.site)（Sites版本可能需要创建者授权；下载后可独立在本地运行。）

## Windows 快速打开

1. 下载本仓库 ZIP 并完整解压，不要在压缩包里直接运行。
2. 电脑需安装 [Node.js](https://nodejs.org/)。
3. 双击根目录的 **打开记忆宫殿.bat**。启动器会在本机启动服务并打开浏览器，不需要先安装项目依赖。

保持启动器、两个辅助脚本和 `palace` 文件夹在同一目录。启动器优先使用 `http://127.0.0.1:5173/`，端口被占用时尝试5174–5178，重复打开会复用已有宫殿服务。关闭浏览器不会停止后台服务，重启电脑后会自动结束。

## 操作

| 操作 | 方法 |
| --- | --- |
| 移动 | WASD / 方向键；Shift 加快 |
| 环顾 | 按住场景拖动，或点击“进入步行模式” |
| 查看物件 | 走近物件，按 E 或直接点击 |
| 宫殿地图 | M |
| 记忆手札 | J |
| 退出阅读 / 释放鼠标 | Esc |
| 触屏 | 方向按钮移动，拖动场景环顾 |

每件物品有四层内容：原创物件独白、原书事件中文转述、原则解释、可反复尝试的选择练习。读完第四页并点击“记下这段记忆”后，在当前浏览器保存进度。

## 八间房

1. 数字的童年：观察价格、交易制度与执行时间。
2. 离开旧方法：重启、等待与独立判断。
3. 风暴的方向：时机、试探和1907年恐慌。
4. 棉花的雪：希望与恐惧、权威与失去自我。
5. 债务的冬天：人情、债务与生活资金保护。
6. 消息的回声：消息传播、经验与新事实。
7. 幕后剧场：历史市场结构、分销与退出。
8. 留给公众的信：宣传、公众责任与全书回望。

## 修改与开发

```sh
cd palace
npm install
npm run dev
```

更新双击启动器读取的正式版本：

```sh
cd palace
npm run build
```

`palace/src/content.js` 保存全书中文文字与情境选择；`palace/src/main.js` 保存 Three.js 场景、碰撞和交互；`palace/style.css` 保存阅读界面。`palace/dist` 是已打包版本，根目录的独立本地服务直接提供这些文件。

三维依赖已经打包，无需脚本CDN；Google中文字体下载为可选项，失败时使用系统字体。浏览器需支持WebGL；无法显示三维时，仍可通过地图和手札阅读。

## 原作与改编

原作：Edwin Lefèvre，*Reminiscences of a Stock Operator*（1923）。[英文原文与下载 · Project Gutenberg #60979](https://www.gutenberg.org/ebooks/60979)。

叙述者拉里·利文斯顿以杰西·利弗莫尔为原型，小说叙述不等于人物完整传记。中文内容为原创转述，不是原书逐字译文，不采用现成中文译本。场景、物件独白、归纳与练习为原创文学改编。内容止于原书，不补入人物1929年交易或1940年死亡。

空间叙事借鉴以物件与环境逐步揭开故事的方式；未复制《伊迪·芬奇的记忆》的素材、角色、对白或音频。历史操纵故事用于理解当时市场，交互中的示意价格不是历史逐笔复现或现实交易建议。
