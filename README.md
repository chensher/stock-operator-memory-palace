# 作手的房子 · 3D 记忆宫殿

用空间、物件和文字阅读《股票作手回忆录》。八间房连接全书24段往事、72个子事件。直接翻纸、拉动、递交或触碰物件，进入连续三维叙述。详尽中文改编与完整英文原文账册可以分别阅读。

[在线体验 · GitHub Pages](https://chensher.github.io/stock-operator-memory-palace/)，无需下载或安装。也可以下载后独立在本地运行。

## Windows 快速打开

1. 下载本仓库 ZIP 并完整解压，不要在压缩包里直接运行。
2. 电脑需安装 [Node.js](https://nodejs.org/)。
3. 双击根目录的 **打开记忆宫殿.bat**。启动器会在本机启动服务并打开浏览器，不需要先安装项目依赖。

保持启动器、两个辅助脚本和 `palace` 文件夹在同一目录。启动器优先使用 `http://127.0.0.1:5173/`，端口被占用时尝试5174–5178，重复打开会复用已有宫殿服务。关闭浏览器不会停止后台服务，重启电脑后会自动结束。

## 操作

| 操作 | 方法 |
| --- | --- |
| 移动 | WASD / 方向键；Shift 加快 |
| 环顾 | 按住场景拖动，或点击“进入步行模式” |
| 查看物件 | 走近物件，按 E 或直接点击 |
| 宫殿地图 | M |
| 事件目录 | J |
| 退出阅读 / 释放鼠标 | Esc |
| 触屏 | 方向按钮移动，拖动场景环顾 |

首页选择“从少年报价员开始，走完全书”，可以顺序体验；也可以在房子中自由进入。剧情在实际物件处等待，没有翻幕按钮。E 替代点击，需要拖动的动作可按住 E；P 暂停、R 重走、Esc 返回。结束后触碰门进入下一段，或打开账册，按 L 切换中文记述与完整英文原文。所有内容自由进入，无需答题或保存进度。

iPad 可以直接触碰、拖动和翻纸。结尾左下角的方向按钮用于走动，可同时用另一只手拖动环顾。账册轻点左、右页或左右滑动翻页；下方“换册”“放回”无需键盘。支持横竖屏布局，按钮触碰高度至少44像素，屏幕旋转或手势中断会释放拖动。已检查常见 iPad 尺寸与触屏逻辑，尚未在实体 iPad Safari 上实测。

## 八间房

1. 数字的童年：观察价格、交易制度与执行时间。
2. 离开旧方法：重启、等待与独立判断。
3. 风暴的方向：时机、试探和1907年恐慌。
4. 棉花的雪：希望与恐惧、权威与失去自我。
5. 债务的冬天：人情、债务与生活资金保护。
6. 消息的回声：消息传播、经验与新事实。
7. 幕后剧场：历史市场结构、分销与退出。
8. 留给公众的信：宣传、公众责任与全书回望。

## 修改与开发

```sh
cd palace
npm install
npm run dev
```

更新双击启动器读取的正式版本：

```sh
cd palace
npm run build
```

`palace/src/content.js` 保存全书中文转述；`palace/src/main.js` 保存 Three.js 场景、碰撞和交互；`palace/style.css` 保存阅读界面。`palace/dist` 是已打包版本，根目录的独立本地服务直接提供这些文件。

三维依赖已经打包，无需脚本CDN；Google中文字体下载为可选项，失败时使用系统字体。浏览器需支持WebGL；无法显示三维时，仍可通过地图和事件目录阅读。

## 原作与改编

原作：Edwin Lefèvre，*Reminiscences of a Stock Operator*（1923）。[英文原文与下载 · Project Gutenberg #60979](https://www.gutenberg.org/ebooks/60979)。

叙述者拉里·利文斯顿以杰西·利弗莫尔为原型，小说叙述不等于人物完整传记。中文内容为原创转述，不是原书逐字译文，不采用现成中文译本。场景、旁白、归纳与物件动作为原创文学改编。内容止于原书，不补入人物1929年交易或1940年死亡。

空间叙事借鉴以物件与环境逐步揭开故事的方式；未复制《伊迪·芬奇的记忆》的素材、角色、对白或音频。历史操纵故事用于理解当时市场，交互中的示意价格不是历史逐笔复现或现实交易建议。
