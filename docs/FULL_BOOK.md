# 全书连续三维版本

24 段往事按原书顺序展开，72 个子事件从实际物件触发。第 3 段保留已经确认的双订单演出，其余 23 段各有三个连续场景。演出内没有剧情选择框、下一幕按钮或来源标注。

空间包括报价行、车站与列车、书房、港口、棉花和谷物仓库、工厂、街道、分销剧场、印刷间和裁缝桌。物件包括粉笔、硬币、订单、箱盖、听筒、钟、椅子、船舵、柜门、帷幕和针线。船只与波浪、列车、人物肢体、纸张转向、柜门、织物缝线和证券分发使用实时几何动画；插画是室内画作。

## 阅读与操作

- 首页选择“从少年报价员开始，走完全书”。也可以进入房子，自由选择事件。
- 点击眼前物件，按提示拖动、翻纸或送入铜盘。E 可以替代点击；需要连续动作时按住 E。
- 文字逐段显示，叙述等待必要的物件动作。P 暂停，R 重走，Esc 返回房子。
- 一段往事结束后可以走动，直接打开下一段往事的门。
- 桌上账册保存更长的中文私人记述。E 往后翻，Shift+E 往前翻，空格放回。L 换到该段对应的完整英文原文。
- 音效按钮控制环境声和操作声。本版没有录制旁白或背景音乐。

## 内容范围

新增演出有 737 段文字、约 19,100 个中文字符，另有第 3 段的原有演出和私人账册。中文是原创文学改编，保留主要事件、数字、判断过程与事后解释，**不是全书逐字中文译本**。更细的原文信息保存在各段英文账册中；24 份原文逐字覆盖正文，未以摘要替代。完整 Gutenberg 文本和附录另存于 `palace/public/source/original.txt`。

原作英文正文取自 Project Gutenberg #60979，来源信息保存在本说明和可选的“关于改编”中。章节对应表及正文摘要指纹见 `manuscript-coverage.json`。未采用现成中文译本。

核对数字时修正了伯利恒钢铁的入场叙述：计划等待越过 100，但实际在 98 至 99 开始买入 500 股；收盘时约 114 或 115，追加 500 股，次日达到 145。动机推测保留为叙述者的事后判断。

## 验证与边界

`cinema-state.mjs` 验证第 3 段完整订单流程、翻纸正反面、声音启停和暂停；`full-novel.mjs` 使用实际三维射线逐一完成其余 69 个物件事件，检查所有叙述得到显示、场景切换、账册分页、窄屏纸张和两种演出引擎的控制归属；`manuscript-coverage.mjs` 对照保存的英文原文检查全部 24 章无正文遗漏。

画面是浏览器里的风格化实时三维演出，并非预渲染电影或商业游戏级角色表演。完整流程自动检查通过，浏览器实测重点检查入口、物件交互、字幕与声音控制，未逐一人工观看全书的每秒画面。
